この章では、Hermes Desktopを導入して起動を確認し、自分に合った始め方を選びます。最初からすべての機能を有効にする必要はありません。まずは「起動して、チャットが打てる」ところまでを最短で目指します。

## 1. インストールする

OSによって配布方法が異なります。すでにHermes AgentのCLIを導入済みなら、ターミナルから起動する方法が手早いです。

### macOS・Windows

1. [公式Downloadページ](https://hermes-agent.nousresearch.com/)を開く。
2. OSに合うHermes Desktopインストーラーを取得する。
3. ダウンロードしたインストーラーを実行する。
4. Hermes Desktopを起動し、ガイド付きセットアップのチャット（「こんにちは、Hermes です。」で始まる）またはチャット画面が表示されることを確認する。

配布物のファイル名、署名、更新方法は変わる可能性があります。第三者のミラーではなく公式サイトから取得してください。

### CLI導入済みの場合

```bash
hermes desktop
```

この方法では、現在の設定、キー、セッション、スキルをDesktop Appと共有します。

### Linux

公式ガイドではDesktop AppはLinuxでも動作するとされています。CLIを公式インストーラーで導入し、`hermes desktop`を実行する方法を確認してください。

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
hermes desktop
```

シェルスクリプトを実行する前に、組織のセキュリティ方針がある場合はスクリプトの内容と配布元を確認してください。管理対象端末では管理者の手順を優先します。

## 2. 起動できたか確認する

次の3つが確認できれば、インストールは成功です。

- Hermes Desktopのウィンドウが開く
- ガイド付きセットアップのチャット、プロバイダー接続の画面、またはチャット画面が表示される
- 設定画面を開ける

起動に失敗する場合は[[05_トラブルシューティング/01_問題の切り分け|問題の切り分け]]を確認してください。

## 3. ガイド付きセットアップを進める

Hermesを一度も使っていないコンピューターでデスクトップアプリを初めて開くと、設定画面ではなく短いセットアップ用のチャットが始まります。このチャットは無料体験用のモデルで動くため、APIキーやアカウントがなくても進められます。

- **前提**: Hermes Desktopが起動し、「こんにちは、Hermes です。」で始まるセットアップチャットが表示されている。
- **操作**: カードが1枚ずつ出るので、順に答えます。
  1. 名前 ─ 呼びかけに使う名前を入力する。
  2. アクセントカラー ─ 画面の強調色を選ぶ。
  3. レイアウト ─ 「ベーシック（Hermes と話すために。）」か「エリート（開発者向け: ターミナル、ファイル、差分。）」を選ぶ。ベーシックはインターフェースモード「シンプル」、エリートは「詳細」に対応し、後から[[03_設定/03_外観|外観]]の「ウィンドウとレイアウト」で切り替えられる。
  4. アプリ ─ つなぎたい外部アプリ（Connectors）を選ぶ。不要なら飛ばしてよい。
  5. プラグイン ─ 入れたいプラグインを選ぶ。不要なら飛ばしてよい。
  6. ツアー ─ 「クイックツアー」「すべて見せて」「スキップして何か作ろう」から選ぶ。
  7. 最初のタスク ─ 提案された最初のタスクを選ぶか、自分で依頼を書く。
- **期待結果**: セットアップが終わると通常のチャットで作業を始められます。コンピューターの性能が足りる場合は、終了時に「このコンピューターはモデルをローカルで実行できます」と表示され、「セットアップする」か「今はしない」を選べます。
- **途中でやめたいとき**: 入力欄の「セットアップをスキップ」を押すと、ガイド付きセットアップを終了して新しいチャットが開きます。後からやり直すには、設定の[[03_設定/08_詳細|詳細]] > デスクトップと起動 にある「オンボーディングをもう一度実行」の「もう一度実行」を押します。

> [!note]
> ガイド付きセットアップは新規のデスクトップ環境で表示されます。すでにHermesを使っている環境や、リモートのバックエンドに接続する構成では表示されないことがあります。表示されない場合や、自分のプロバイダーをすぐ使いたい場合は、従来どおり[[03_設定/09_プロバイダー|プロバイダー]]からアカウント接続やAPIキー登録を行えます。無料体験モデルは初回セットアップ向けのため、日常の作業には自分で接続したプロバイダーのモデルを使ってください。

## 4. 3段階クイックスタート

起動できたら、自分の状況に合わせて始め方を選びます。下にいくほど設定項目が増えますが、**最小限から始めて後で広げて構いません**。迷ったら最小限を選んでください。

### 最小限 ─ まずチャットを打ちたい

「とにかく動かしたい」段階向けです。ガイド付きセットアップのあとに、プロバイダーを1つ接続すれば完結します。

1. 設定の[[03_設定/09_プロバイダー|プロバイダー]]で、利用するモデルプロバイダーへサインインするか、APIキーを登録する。
2. チャットで使うプロバイダーとモデルを1つ選び、適用する（ツール呼び出しに対応するモデルを選ぶと、後の章の操作がそのまま使える）。
3. 影響の小さい確認タスクからチャットを始める。

この段階では、承認モードや作業フォルダは初期設定のまま進めて問題ありません。詳しいモデル選びは[[09_入門コース/05_モデルとプロバイダーを整える|モデルとプロバイダーを整える]]で扱います。

### 標準 ─ 安全に日常使いしたい

ファイルを扱う実作業に入る前の、推奨の出発点です。最小限に次を足します。

1. 作業フォルダを、対象プロジェクトまたは専用のテストフォルダに限定する。
2. 設定の安全性 > 承認 で、承認モードを `manual`（UI表示は「手動」。承認が必要な操作の前に人が確認する）に設定する。既定は `smart`（UI表示は「スマート」。LLMレビュアーが低リスクのコマンドを自動承認する）なので、標準の安全運用では手動へ切り替えます。
3. 設定の安全性 > プライバシーとネットワーク で「シークレットを伏せる」がオンであることを確認する。
4. コード編集を行うなら、安全性 > チェックポイント でファイルチェックポイントをオンにする。

安全設定の意味は[[09_入門コース/06_安全に使う設定|安全に使う設定]]で詳しく扱います。チェックリストは[[04_ガイド/03_安全に設定するための確認事項|安全に設定するための確認事項]]が便利です。

### 高度 ─ 用途ごとに作り込みたい

複数の用途を使い分けたい段階向けです。標準に次を足します。

1. 速度や費用が気になるタスクだけ、補助モデルを別モデルに分離する。
2. 業務継続が必要なら、別プロバイダーのフォールバックを1〜2個登録する。
3. 外部ツールを使うなら[[09_入門コース/07_MCPで能力を広げる|MCP]]を、作業手順を再利用するなら[[09_入門コース/08_スキルとプロファイルを使う|スキルとプロファイル]]を設定する。

高度な構成は、必要が出てから一つずつ足すのが安全です。最初から全部やろうとしないでください。

## つまずいたら

- **インストーラーが見つからない・古い**: 第三者サイトではなく[公式Downloadページ](https://hermes-agent.nousresearch.com/)から取得し直す。
- **`hermes desktop` が動かない**: CLIが導入済みか、`hermes` にパスが通っているかを確認する。未導入なら公式インストーラーで入れる。
- **起動するがプロバイダーに繋がらない**: ガイド付きセットアップをスキップした場合や表示されなかった場合も、設定画面から後で接続できる。詳細は[[03_設定/09_プロバイダー|プロバイダー]]を参照。
- **セットアップをやり直したい**: 設定の詳細 > デスクトップと起動 にある「オンボーディングをもう一度実行」を使う。
- **それでも起動しない**: [[05_トラブルシューティング/01_問題の切り分け|問題の切り分け]]で症状から原因を絞り込む。
