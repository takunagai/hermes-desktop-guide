音声会話のモード、音声入力（STT）、読み上げ（TTS）を設定する。利用できるプロバイダーはこのビルドの画面定義に限定して記載する。

![](@editorial/editorial-03-girl-winged-helmet.webp)

![設定 > 音声 > 音声会話 画面](@screenshots/settings-voice.webp)

表示値は環境依存の例。

> [!note] 「適用対象」チップ（プロファイルが 2 つ以上あるとき）
> プロファイルを 2 つ以上作成していると、画面上部に「適用対象」という見出しとプロファイル名のチップ列が表示される。チップを選ぶと「このページの変更は「◯◯」プロファイルに適用されます。」と表示され、この画面の編集がそのプロファイルの `config.yaml` に書き込まれる。選択は設定画面の他のページへ移動しても保持される。プロファイルが 1 つだけの環境では表示されない。

> [!note] 3 つの子項目に共通の案内行「音声録音ショートカット」
> 音声画面のどの子項目でも、先頭に「「設定 → キーボードショートカット」で音声録音ショートカット（「Start / stop voice conversation」）を設定します。voice.record_key は CLI と TUI 専用です。」という案内行が出る。デスクトップの録音ショートカットは音声画面ではなく、[[03_設定/17_キーボードショートカット|キーボードショートカット]]の子項目「キー割り当て」で設定する（案内文の「キーボードショートカット」は画面名で、子項目名は「キー割り当て」）。既定は ⌃B。

> [!note] 画面の挙動 ─ 選択中プロバイダーのサブ欄のみ表示
> プロバイダー別のサブ設定欄は、選択中のプロバイダーの分だけ表示される。音声認識をオフにすると STT のサブ設定欄も非表示になる。

> [!note] 音声・モデル名欄の入力方式
> 音声・モデル名の 24 欄は**自由入力コンボボックス**。既知の候補はサジェストとして表示され、候補にない ID（ElevenLabs のクローン音声、xAI のカスタム音声、Edge の 400 種超のカタログ音声など）も直接入力できる。STT のモデル欄（OpenAI / Groq / Mistral / xAI / DeepInfra）と ElevenLabs TTS モデルも自由入力になっている。閉じた選択リストのままなのは、ローカル文字起こしモデル、ElevenLabs STT モデル、OpenAI Live Transcription Model、NeuTTS デバイス。

音声画面はサイドバーの子項目として次の 3 つに分かれている。画面を開くと先頭の「音声会話」が表示される。

| 子項目 | 主な項目 |
|---|---|
| 音声会話 | Voice Chat Mode、GPT-Live Voice、GPT-Live Persona、最大録音時間、Client Direct |
| 音声認識 | 音声認識、Echo Transcripts、音声認識プロバイダー、Live Transcription、プロバイダー別のモデル・言語 |
| 音声合成 | 音声合成プロバイダー、応答を読み上げる、プロバイダー別のモデル・音声 |

この画面で新しく加わった項目の多くは、日本語リソース未整備のため日本語 UI でも英語のラベル・説明文で表示される。

## 音声会話

| 画面表示（主） | 内部キー（サブ） | 製品既定値 | 推奨 |
|---|---|---:|---|
| Voice Chat Mode（英語表示） | `voice.voice_chat_mode` | `chained` | 通常は `chained` |
| GPT-Live Voice（英語表示） | `voice.gpt_live.voice` | `marin` | 好みで |
| GPT-Live Persona（英語表示） | `voice.gpt_live.instructions` | 空欄（表示は「未設定」） | 必要なときだけ記入 |
| 最大録音時間 | `voice.max_recording_seconds` | `120` 秒 | 60～120秒 |
| Client Direct（英語表示） | `voice.client_direct` | オン | 通常オンのまま |

### 音声会話モード（Voice Chat Mode）

デスクトップの音声会話をどう組み立てるかを選ぶ。説明文は英語表示。

| 画面表示（主） | 保存値（内部） | 既定 | 動作 |
|---|---|---|---|
| Chained | `chained` | はい | 音声認識 → Hermes → 音声合成の順につなぐ。下の「音声認識」「音声合成」で選んだプロバイダーを使う |
| Gpt-Live | `gpt-live` | いいえ | OpenAI の全二重音声モデル `gpt-live-1` が聞き取りと発話を担い、実際の依頼はすべて Hermes へ渡す。応答は選択中のモデルがツール込みで返す |

- `gpt-live` には OpenAI の API キーが必要。説明文によると、音声層は 1 分あたり $0.05 が課金される（2026-10-15 時点の画面表示。料金は OpenAI 側で変わり得る）。
- `gpt-live` が使えない状態で音声会話を始めると、「GPT-Live voice chat is not available: …. Using speech-to-text instead.」と表示され（英語表示）、音声認識による方式に切り替わる。

### GPT-Live の声とペルソナ

- **GPT-Live Voice**（`voice.gpt_live.voice`）: `gpt-live` モードで使う声。自由入力のコンボボックスで、候補は `marin`（既定）、`cedar`、`quartz`、`ripple`、`vesper`、`willow`、`stone`、`gleam`、`meridian`、`bossa`、`tempo`、`beacon`、`delta`、`cinder` の 14 種。候補にない声の ID も入力できる。
- **GPT-Live Persona**（`voice.gpt_live.instructions`）: ライブ音声の話し方（口調・速さ・言語など）に足す指示文。空欄が既定。Hermes 本体のシステムプロンプトはそのまま使われる。日本語で話させたい場合は「日本語で、落ち着いた口調で話す」のように書く。
- どちらも `chained` モードでは使われない。

> [!note] Client Direct
> 「音声会話」の最下段にあるトグル。ラベルに日本語訳がなく説明文も無いため、日本語 UI でも英語の「Client Direct」とだけ表示される。オンのとき、デスクトップのリモートクライアントは、音声セッション開始時に認証済みの REST 経由でプロバイダーの設定とキーを受け取り、選択中の STT / TTS プロバイダーへ**直接**音声を送受信する（ゲートウェイを経由しない最短経路）。対応する経路は OpenAI 互換の文字起こし・読み上げ、xAI の文字起こし、ElevenLabs の文字起こし・読み上げ。ローカル whisper、Edge TTS、コマンド型やプラグインのプロバイダーなど、ゲートウェイ側でしか動かないものは自動的に従来どおりのリレー経路になる。オフにすると、すべてのプロバイダーで常にゲートウェイ経由のリレーになる。

### 録音ショートカット

デスクトップの録音開始・停止のキーは、この画面ではなく [[03_設定/17_キーボードショートカット|キーボードショートカット]] > キー割り当ての「Start / stop voice conversation」（既定 ⌃B）で変更する。`config.yaml` の `voice.record_key`（既定 `ctrl+b`）は CLI と TUI だけが使う。

## 音声認識

| 画面表示（主） | 内部キー（サブ） | 製品既定値 | 推奨 |
|---|---|---:|---|
| 音声認識 | `stt.enabled` | オン | 音声入力を使う場合オン |
| Echo Transcripts（英語表示） | `stt.echo_transcripts` | オン | トランスクリプトの投稿が不要ならオフ |
| 音声認識プロバイダー | `stt.provider` | 未設定（自動検出。ローカルを優先） | プライバシー重視は `local` を明示 |
| Live Transcription（英語表示） | `stt.streaming` | オフ | 話しながら文字を見たいならオン |

> [!note] 音声認識プロバイダーの既定は「未設定」
> 製品既定設定には `stt.provider` キーが含まれない。保存された `stt.provider` は「ユーザーが明示的に選んだ値」として扱われるため、初期状態と区別できるように既定値を持たせていない。未設定のときは自動検出が働き、ローカルの `faster-whisper` が優先される。画面のドロップダウンで一度でも選ぶと、その値が明示的な選択として `config.yaml` に保存される。

> [!note] Echo Transcripts
> ゲートウェイ経由の音声メッセージを文字起こしした際、生のトランスクリプトを 🎙️ 付きメッセージとしてチャットへ投稿し返す設定。日本語ラベルが未翻訳のため、日本語 UI でも英語の「Echo Transcripts」と表示される。オフにしてもエージェントへの文字起こし自体は維持され、ユーザー向けのエコー投稿だけが止まる。プロバイダー別の欄と違い、この欄は常時表示される。

### Live Transcription

説明文は「Show text while you speak (OpenAI, xAI, ElevenLabs). Falls back to the recording on any failure.」（英語表示）。オンにすると、話している最中から文字起こしが表示される。**既定はオフ**。

- 対応するのは音声認識プロバイダーが OpenAI / xAI / ElevenLabs のとき。OpenAI では「OpenAI Live Transcription Model」（既定 `gpt-live-transcribe`）が使われる。
- ライブ文字起こしが失敗した場合は、録音した音声を通常どおり文字起こしする方式へ自動で戻る。

### 音声認識プロバイダー

| 画面表示（主） | 保存値（内部） | 既定 | 実行場所・特徴 | 必要なもの |
|---|---|---|---|---|
| Local | `local` | はい | `faster-whisper` をローカル実行。音声を外部 STT API へ送らない | 初回モデル取得、ローカル CPU / GPU |
| Groq | `groq` | いいえ | Groq の Whisper 互換 API。低遅延を重視 | `GROQ_API_KEY`。このキーは本画面ではなく環境設定側で管理される場合がある |
| Openai | `openai` | いいえ | OpenAI の Whisper / Transcribe API | `VOICE_TOOLS_OPENAI_KEY` |
| Mistral | `mistral` | いいえ | Mistral の音声文字起こし API | Mistral の API 認証（`MISTRAL_API_KEY`） |
| Xai | `xai` | いいえ | xAI の音声文字起こし。整形、対応言語、話者処理はサービス仕様に依存 | xAI API キーまたは利用可能な xAI 認証 |
| Elevenlabs | `elevenlabs` | いいえ | ElevenLabs Scribe を使い、言語指定、音声イベント、話者分離を設定可能 | `ELEVENLABS_API_KEY` |
| Deepinfra | `deepinfra` | いいえ | DeepInfra の音声文字起こし。モデルは DeepInfra のカタログから選ぶ | DeepInfra の API 認証 |

> [!tip] 上級者向け ─ TTS / STT プロバイダーを config で自作できる
> `config.yaml` の `tts.providers.<名前>` / `stt.providers.<名前>` に `command` を持つブロックを定義すると、設定画面ではその名前がプロバイダードロップダウンの候補に加わる（ユーザー定義コマンドプロバイダー）。`type: command` は省略可能で、`command` に空でない文字列が必須。組み込みプロバイダー名（`edge` など）と同名の定義は無視される。後方互換として `tts.<名前>` 直下のトップレベル定義も解決される。

以下のサブ設定欄は、`stt.provider` で選択中のプロバイダーの分だけが表示される。音声認識をオフにすると全サブ欄が非表示になる。

| 画面表示（主） | 内部キー（サブ） | 製品既定値 | 推奨 |
|---|---|---:|---|
| ローカル文字起こしモデル | `stt.local.model` | `base` | 速度重視 `base`、精度重視 `small` 以上 |
| 文字起こし言語 | `stt.local.language` | 空欄（自動） | 日本語固定が必要なら言語コード |
| OpenAI STT モデル | `stt.openai.model` | `whisper-1` | 自由入力。候補 `whisper-1` / `gpt-4o-mini-transcribe` / `gpt-4o-transcribe` / `gpt-transcribe` |
| OpenAI Live Transcription Model（英語表示） | `stt.openai.streaming_model` | `gpt-live-transcribe` | Live Transcription 用。候補 `gpt-live-transcribe` / `gpt-transcribe` / `gpt-4o-transcribe` / `gpt-4o-mini-transcribe` から選択 |
| Groq STT モデル | `stt.groq.model` | `whisper-large-v3-turbo` | 自由入力。候補 `whisper-large-v3-turbo` / `whisper-large-v3` |
| Mistral STT モデル | `stt.mistral.model` | `voxtral-mini-latest` | 自由入力。候補 `voxtral-mini-latest` / `voxtral-mini-2602` |
| xAI STT Model（英語表示） | `stt.xai.model` | 空欄（`grok-voice-transcribe-2.0` を使う） | 自由入力。候補 `grok-voice-transcribe-2.0` / `grok-voice-transcribe-1.0` |
| DeepInfra STT Model（英語表示） | `stt.deepinfra.model` | 空欄（DeepInfra のライブカタログで最初に見つかる文字起こしモデル） | 自由入力 |
| ElevenLabs STT モデル | `stt.elevenlabs.model_id` | `scribe_v2` | `scribe_v2` |
| ElevenLabs 言語 | `stt.elevenlabs.language_code` | 空欄（自動） | 必要時に ISO-639-3 |
| 音声イベントをタグ付け | `stt.elevenlabs.tag_audio_events` | オフ | 会話分析時のみオン |
| 話者分離 | `stt.elevenlabs.diarize` | オフ | 複数話者の録音時のみオン |

#### ローカル文字起こしモデルの全候補

| 画面表示（主） | 保存値（内部） | 既定 | 相対的な速度・精度 | 用途 |
|---|---|---|---|---|
| Tiny | `tiny` | いいえ | 最速・最小、精度は低め | 動作確認、低性能端末 |
| Base | `base` | はい | 高速で標準的 | 短い日常音声 |
| Small | `small` | いいえ | 中程度 | 日本語精度を少し上げたい場合 |
| Medium | `medium` | いいえ | 低速・高精度 | 精度優先、十分なメモリがある端末 |
| Large-v3 | `large-v3` | いいえ | 最も重い・高精度 | 品質最優先、強い CPU / GPU |
| Turbo | `turbo` | いいえ | large-v3 を軽量化した高速版 | 高い精度を保ちつつ速度も欲しい場合 |

#### ElevenLabs STT モデルの全候補

| 画面表示（主） | 保存値（内部） | 既定 | 動作 |
|---|---|---|---|
| Scribe V2 | `scribe_v2` | はい | 新しい Scribe 系モデル |
| Scribe V1 | `scribe_v1` | いいえ | 旧 Scribe モデル。互換性や比較が必要な場合 |

#### 言語と追加解析

- **文字起こし言語**: 空欄では `faster-whisper` が自動検出する。固定する場合は `ja`, `en` などの対応言語コードを入力する。
- **ElevenLabs 言語**: 空欄では自動検出。固定時は ElevenLabs が受け付ける ISO-639-3 コードを使う。
- **音声イベントをタグ付け オン**: 笑い声、拍手など、音声中の非発話イベントを文字起こしへ含める。
- **音声イベントをタグ付け オフ**: 発話本文を中心に返す。
- **話者分離 オン**: 複数話者を識別した結果を要求する。処理量や出力複雑度が増える。
- **話者分離 オフ**: 話者を分けず単一の文字起こしとして扱う。

### 音声合成のプロバイダー別の欄

以下のサブ設定欄は、`tts.provider` で選択中のプロバイダーの分だけが表示される。

| 画面表示（主） | 内部キー（サブ） | 製品既定値 | 入力・動作 |

#### OpenAI 音声の既定候補

既定候補は 13 種（`gpt-4o-mini-tts` 世代）。

`alloy`（既定）、`ash`、`ballad`、`cedar`、`coral`、`echo`、`fable`、`marin`、`nova`、`onyx`、`sage`、`shimmer`、`verse`

音声のサジェストは **「OpenAI TTS モデル」で選んだモデルに応じて絞り込まれる**。`tts-1` / `tts-1-hd` を選ぶと候補は 9 音声になる（残る 4 音声は `gpt-4o-mini-tts` 専用のため）。実際に選べる音声はモデルを選び直した後のサジェストを正とする。

音色の印象はモデルや API 側の更新で変わり得るため、名前から固定的な性別・声質を断定せず、実際に短文を読み上げて選ぶ。

## 録音操作

- **音声認識 オン**: 受信・録音した音声を選択プロバイダーで自動文字起こしする。
- **音声認識 オフ**: 自動文字起こしを行わない。ゲートウェイでは音声ファイル自体が保持・参照される場合がある。
- **Echo Transcripts オン**: ゲートウェイ経由の音声メッセージを文字起こしした際、生のトランスクリプトを 🎙️ 付きメッセージとしてチャットへ投稿し返す。
- **Echo Transcripts オフ**: エージェントへの文字起こしは維持したまま、チャットへのエコー投稿だけを止める。
- **応答を読み上げる オン**: アシスタントの応答を選択した TTS で自動再生する。
- **応答を読み上げる オフ**: 必要なときだけ手動の音声機能を使う。
- **録音ショートカット**: デスクトップでは [[03_設定/17_キーボードショートカット|キーボードショートカット]] > キー割り当てで変更する。OS や他アプリのショートカットと競合しないキーを使う。
- **最大録音時間**: 1回の録音を停止するまでの上限秒数。長くするとファイルサイズと文字起こし時間が増える。

## 画面に入力欄が無い設定値

音声まわりには、設定画面に入力欄がなく `config.yaml` でだけ設定できるキーがある。

> [!tip] 日本語で音声入力するなら `stt.language` を確認する
> `stt.language` は STT のグローバル既定言語で、既定は `en`。日本語で音声入力する運用では変更が要る（例: `stt.language: ja`）。プロバイダー別の言語欄（`stt.local.language`、`stt.elevenlabs.language_code`）とは別のグローバル既定。

| 設定キー | 既定 | 内容 |
|---|---|---|
| `stt.language` | `en` | STT のグローバル既定言語 |
| `voice.submit_mode` | `direct` | TUI で文字起こし後の扱い。`direct` は即送信、`draft` は編集できる下書きとして入力欄に残す。値はこの 2 つだけで、他の文字列は設定読み込み時にエラーになる |
| `stt.cloud_trim_silence` | オン | アップロード前にクライアント側で無音をトリムする。送信時間・課金・幻覚（無音部分の誤認識）を減らす |
| `voice.barge_in` | オン | ユーザーが話し始めると、読み上げとエージェントを割り込み停止する |
| `voice.barge_in_grace_seconds` | `0.5` 秒 | 再生直後の誤トリガーを抑える猶予時間 |
| `voice.stop_phrases` | `['stop']` | 完全一致したら音声チャットを終了するフレーズ |
| `voice.thinking_sound` | オン | 音声チャット中に思考音を鳴らす |
| `voice.beep_volume` | `0.3` | ビープ音の音量 |
| `voice.record_key` | `ctrl+b` | CLI と TUI の録音キー。デスクトップはキーボードショートカット画面で設定する |

### ウェイクワード（`wake_word`）

ハンズフリーで音声チャットを始めるためのウェイクワード検出。**既定はオフ**。検出は端末内で完結し、音声が機器の外へ出ることはない。

| 設定キー | 既定 | 内容 |
|---|---|---|
| `wake_word.provider` | `auto` | 検出エンジン。下表の 4 種 |
| `wake_word.phrase` | `hey hermes` | 検出するフレーズ |
| `wake_word.sensitivity` | `0.6` | 検出感度。上げると反応しやすく、誤検出も増える |

| `provider` の値 | 費用 | 特徴 |
|---|---|---|
| `auto` | ─ | 既定。`openwakeword` → `sherpa` → `porcupine` の順に、使えるエンジンを自動で選ぶ |
| `openwakeword` | 無料 | ローカル実行 |
| `sherpa` | 無料 | 任意のフレーズを使える。訓練は不要 |
| `porcupine` | 有料 | API キーが必要 |

## 推奨構成

- ローカル・無料重視: STT `local` + `base`、TTS `edge`、自動読み上げオフ。
- 日本語精度重視: STT の言語を固定し、必要に応じて `small` 以上。
- 会議録: ElevenLabs の話者分離を有効化し、送信先のデータ方針を確認。
