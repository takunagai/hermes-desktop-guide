設定画面の順序と項目のチェック用索引。2026-06-20 に起動中の v0.17.0 日本語 UI を全画面採取して作成し（ペット・MoA は 2026-07-01）、2026-07-02 に v0.18.0 で差分更新、2026-07-22 に v0.19.0（コミット `967e078`）の同一コミットソース（設定画面定義・日本語ラベル `i18n/ja.ts`・バックエンド既定値 `DEFAULT_CONFIG`）で差分更新した。

画面構成は v0.19.0 で **15 画面 → 17 画面**に変わった。「請求」「キーボードショートカット」「Plugins」の 3 画面が新設され、「MCP」は設定タブから削除されて Capabilities ページ（`/skills?tab=mcp`）へ移動した。ナビの並び順は次のとおり（区切り線 2 本を含む）。

1. 設定セクション 8 つ（モデル / チャット / 外観 / ワークスペース / 安全性 / メモリとコンテキスト / 音声 / 詳細）
2. 通知 → 請求
3. ─ 区切り ─ プロバイダー → ゲートウェイ → キーボードショートカット → ツールとキー → Plugins → アーカイブ済みチャット
4. ─ 区切り ─ 情報

表の「画面表示（主）」は実際に見える文字列、「内部キー（サブ）」は設定 API・設定ファイル・`.env`・デスクトップ保存領域で使う名前。内部キーだけを画面ラベルとして扱わない。ボタンなど永続キーを持たないものは、内部操作名または「操作・保存キーなし」、既定値は「該当なし」と記載する。「未設定（実効: 値）」は、保存値は空だが実行時に括弧内へ解決されることを示す。v0.19 新設画面の本文は日本語リソース未整備のため英語表示が残る（ナビラベルのみ日本語）。該当箇所は行内に明記する。
